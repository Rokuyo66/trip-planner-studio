# Trip Planner Studio

產出一個單檔網頁 `trip.html`：使用者改日期、天數、人數、交通方式、住宿或拖移景點，路線、時間、費用都會即時重算。照片由使用者自己放進資料夾，頁面上按「重整照片」就會讀進來，不需要再找 Claude。

## 流程

### 1. 確認需求（缺的才問，一次問完）

- 目的地國家／城市、出發城市（預設台北）、大概日期或季節、天數
- 人數與房型偏好、旅遊傾向（省錢／CP 值／休閒）、預算感
- 有沒有一定要去的點、餐廳或路線（放進 `DEFAULTS.must`）
- 上班族要考慮請假：查當地與出發地的連假，建議避開人潮或用連假省假

### 2. 查資料（每項都要可以附來源）

用網路搜尋查**現在**的資訊，不要憑記憶：

- 必看景點：開放時間、休館日、門票、是否要預約時段
- 餐廳：每天午晚餐都要有具名的店（評價好、價位合理、確認營業日與行程日期不衝突）
- 住宿：每城市三選一（主選、備案、省錢），可加一間高檔選項；要有房型與可住人數
- 交通：機場進市區、城際火車或巴士班次與票價、市區單程票與一日票上限、租車與停車費
- 一日團：自己去不方便的地方（要預約、交通難、需要酒駕的酒莊）找 1～3 個評價好的團，記下價格、時間、包含項目、評分與網址
- 申辦：簽證或旅行授權、住宿稅、付款習慣與現金、緊急聯絡（台灣駐外代表處；使用者需要時加上其他國家大使館）
- 建議住宿策略：至少兩種。多城市行程用「少換飯店」和「順路輕鬆」；只住一個城市時，第二種可以是「在一日遊的地方住一晚」
- 餐廳和景點的**營業時間**也要記下來（寫進 `memo`），排程時要用

### 2b. 排每天行程的規則

- **先決定日期再排餐廳**：用出發日推出每天是星期幾，公休日寫進 `PLACES.closed`。`check_data.mjs` 會擋下排在公休日的店。
- **每一餐換一家**：同一家店不要在兩天出現（檢查會提醒）。不夠的話，先查更多店，不要重複。
- **用餐時間要落在營業時間內**：午餐別排在開門前、晚餐別排在最後點餐之後。早上景點停留時間不夠撐到午餐開門時，加長停留（例如把老街散步併進景點時間）或把出發時間往後。
- **傍晚才好看的點**（夕陽、點燈、夜櫻、表演）用 `VISIT` 的固定開始時間；早上有名額或怕人多的點，把當天 `start` 提早。
- **旅遊傾向「休閒」**：每天最多 2 個主景點加午晚餐，其他放進 `CANDS`。市場邊逛邊吃當午餐時，`VISIT` 類型寫 `meal`，不要寫 `visit`，不然會被算成景點。
- **短程航線**（例如台灣飛日本、韓國）：設 `TRIP_META.homeDay:false`、D1 就入住，去程 `flight` 後面接一段 `fixed` 代表飛行＋入境時間，細節見 `reference/data-format.md`。回程日的 `start` 設在退房後，讓時間軸把午餐排在機場。
- **非歐元幣別**：設 `TRIP_META.local`、`curName`、`k`，所有價格直接填當地幣。`fx` 是 1 單位當地幣等於多少台幣（日圓約 0.2）。計程車、城際火車的估價用 `taxi`、`rail` 填當地的費率。

### 3. 產生行程頁

1. 把 `template/trip.html` 複製到使用者的工作資料夾，例如 `京都自由行/trip.html`。
2. 只替換 `TRIP DATA START` 到 `TRIP DATA END` 之間的資料，格式見 `reference/data-format.md`。範本裡的葡萄牙資料是長程、歐元、多城市的完整範例；`reference/example-kyoto.js` 是短程、日圓、單一城市的範例。照比較接近的那份寫。引擎部分不要動；引擎不支援的需求，先看 `data-format.md` 的「幣別與地區設定」有沒有對應欄位。
3. 同時改掉檔案開頭 `<title>` 與 `<h1 id="hTitle">`、`id="barTitle"` 的預設標題。
4. 地圖國界：
   ```
   npm pack world-atlas@2 && tar xzf world-atlas-2*.tgz
   python3 scripts/make_map_geo.py package/countries-10m.json 主要國家 鄰國 --bbox 西,東,南,北
   ```
   把輸出的兩行貼進資料區，取代 `MAP_GEO` 與 `MAP_BOUNDS`。
5. 檢查：`node scripts/check_data.mjs trip.html`，有錯誤就修到通過，輸出裡的「注意：」也逐條看過。
6. 逐天看時間軸：能裝 Playwright 的話執行 `python3 scripts/render_check.py trip.html`（有第二種住宿策略再加 `--strat 鍵名` 跑一次），不能的話用瀏覽器逐天點開。對照營業時間檢查每一餐的開始時間、有固定時間的點前面有沒有不合理的長空檔，頁面錯誤要是「無」。
7. 一日團要排進行程：可取代某天的寫 `for:'tN'`，可另外加一天的寫 `add:'城市'`。在說明裡寫出你推薦的理由，`src` 放來源網址。

### 4. 建照片資料夾

```
node scripts/make_photo_folders.mjs trip.html 京都自由行/照片
```

每個景點、餐廳、住宿、一日團、交通站各一個資料夾，名稱結尾的 `[id]` 讓頁面認得照片。

### 4b. 如果碰不到使用者的電腦

在 claude.ai 網頁或 App 對話裡，資料夾只會建在雲端工作區：把整個「照片」資料夾壓成 zip、連同 `trip.html` 一起給使用者下載，請他解壓到自己電腦上。

### 5. 交付

告訴使用者：

- 用 Chrome 或 Edge 打開 `trip.html`（下載到電腦後直接雙擊）。
- 第一次：右上角「選單 → 存檔 → 選擇照片資料夾」，選「照片」資料夾。
- 之後補照片：按右上角「重整照片」，只會處理新增或改過的照片。照片縮小後存在這台電腦的瀏覽器裡。
- 要發佈成可分享的網頁（例如 Claude 的 Artifact 或自己的網站）：執行 `python3 scripts/build_photos.py 照片 trip.html`，會產生 `img/` 縮圖並把清單寫進頁面，然後把 `trip.html` 和 `img/` 一起上傳。

最後一段附上所有查資料用到的來源連結。

## 注意

- 價格、時間、營業日都標「約」或附來源，請使用者出發前確認。
- 不要把使用者的照片或個人資料放進公開的地方。
- 頁面完全在本機運作；只有 Google 字型和 Google 地圖／Google Flights 連結會連網。
